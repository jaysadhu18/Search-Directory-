# Samaj Directory — Client

React + Vite front end for the Samaj Directory app. Talks to the API in `../server`
(proxied from `/api` to `http://localhost:5000` in dev — see `vite.config.js`).

## Scripts

- `npm run dev` — start the Vite dev server on http://localhost:3000
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build locally
